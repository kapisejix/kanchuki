## Fix diffs (proposed, NOT applied)

F1 — `apps/api/src/jobs/index.ts`

```diff
+import * as Sentry from '@sentry/node';
 ...
+function reportFailed(queue: string) {
+  return (job: { id?: string; name?: string } | undefined, err: Error) => {
+    console.error(`[jobs] ${queue} (${job?.name}) failed ${job?.id}:`, err.message);
+    Sentry.captureException(err, { tags: { queue, job: job?.name ?? 'unknown' } });
+  };
+}
 ...
-  maintenanceWorker.on('failed', (job, err) => {
-    console.error(`[jobs] maintenance (${job?.name}) failed ${job?.id}:`, err.message);
-  });
+  maintenanceWorker.on('failed', reportFailed('maintenance'));
```

Same one-line swap for the other six listeners (tagging, embedding, studio-shoot, try-on, my-style-analyze, push, catalog-sync). Sentry is a no-op until `SENTRY_DSN` is set, so this is safe to ship. The try-on and my-style queues handle customer photos; the capture carries only `err` and tags, not job data.
