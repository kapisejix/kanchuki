## Fix diffs (proposed, NOT applied)

F1 — new `apps/api/src/lib/fetch-timeout.ts`:

```ts
// Node fetch has no short overall deadline; every outbound call gets one.
export const fetchT = (url: string | URL, init: RequestInit = {}, ms = 15_000) =>
  fetch(url, { ...init, signal: init.signal ?? AbortSignal.timeout(ms) });
```

`apps/api/src/lib/email.ts:45`

```diff
-    const res = await fetch('https://api.resend.com/emails', {
+    const res = await fetchT('https://api.resend.com/emails', {
```

The other 36 call sites get the same swap. A timeout throws `TimeoutError`; each caller must map that to a sensible message, which I did not check for all 37.

F2 — new `apps/api/src/lib/prisma-errors.ts`:

```ts
const EXPECTED = new Set(['P2025', 'P2002']);
// null only for "row not found" / "duplicate"; any other error is a real failure.
export const nullOnMissing = (e: unknown): null => {
  if (EXPECTED.has((e as { code?: string })?.code ?? '')) return null;
  throw e;
};
```

Then `.catch(() => null)` becomes `.catch(nullOnMissing)` at the 17 sites.
