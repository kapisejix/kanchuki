## Proof

F1/F2 — real `adminAuthPreHandler`, request carrying only `x-admin-key` (what the pages send):

```
POST /v1/admin/query -> Invalid CSRF token — include x-csrf-token header matching csrf-token cookie
DELETE /v1/admin/social/accounts/abc -> Invalid CSRF token — include x-csrf-token header matching csrf-token cookie
GET /v1/admin/social/accounts -> PASS
```

F3 — real `admin-fetch.ts`, fetch stub fails once (503) then would succeed:

```
call 1 FAIL CSRF token fetch failed: HTTP 503 fetches: 1
call 2 FAIL CSRF token fetch failed: HTTP 503 fetches: 1
call 3 FAIL CSRF token fetch failed: HTTP 503 fetches: 1
```
Retries never reach the network.
